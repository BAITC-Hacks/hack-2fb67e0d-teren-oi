# Teren Oi — сравнение организационных документов

MVP для хакатона: сравнивает две редакции положения об организации, показывает точные изменения по пунктам и, при наличии OpenAI API key, формирует аналитические выводы с проверяемыми ссылками на пункты-источники.

## Что уже предусмотрено

- Загрузка двух файлов DOCX («до» и «после»).
- Извлечение абзацев и таблиц в исходном порядке, нумерованных пунктов и дословных фрагментов.
- Точный diff по номеру пункта: добавлено, удалено, изменено, без изменений.
- Опциональный AI-анализ только изменённых пунктов. Ссылки на источники проверяются приложением по разрешённому набору пунктов.
- Выгрузка отчёта в Markdown и JSON.
- Если ключ не задан, приложение всё равно работает как детерминированный diff-инструмент.

## Запуск на Windows

Требуется Python 3.11 или новее.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e .
Copy-Item .env.example .env
streamlit run app.py
```

Чтобы включить AI-анализ, добавьте `OPENAI_API_KEY` в `.env`. Не вставляйте ключ в исходники и не коммитьте `.env`. Модель задаётся переменной `OPENAI_MODEL`.

## Структура

```text
app.py                       Streamlit-интерфейс
src/teren_oi/models.py       Общие типы и схема AI-ответа
src/teren_oi/docx_reader.py  Извлечение текста и пунктов из DOCX
src/teren_oi/diff.py         Точный структурный diff
src/teren_oi/analyzer.py     Опциональный AI-анализ и проверка ссылок
src/teren_oi/report.py       Экспорт отчёта
```

## Границы MVP

- Сейчас поддерживается DOCX. PDF, сканы/OCR и Excel — отдельные следующие этапы.
- Сопоставление использует номера пунктов. Если пункт перенумерован, он может отобразиться как удалённый и новый; позже добавим сопоставление по смыслу.
- AI-выводы — гипотезы для проверки человеком, а не юридическое заключение. Точный diff всегда показывается отдельно.
- Документы не загружаются в сторонний AI-сервис без настроенного API-ключа и явного запуска анализа.
